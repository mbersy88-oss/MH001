\# Development Rules



\## Purpose



Define the development standards for Barsi OS.



\## Rules



1\. All changes must be version controlled.

2\. All architecture changes require documentation.

3\. No duplicate systems or data sources.

4\. Security must be considered from the beginning.

5\. All major decisions require an ADR.

6\. Testing is required before release.



\## Branching



main:

Production-ready code.



phase branches:

Development and testing.



\## Quality Principle



Build stable foundations before adding complexity.
